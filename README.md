# Project1_Week7_SequenceAnalysis
## Purpose
The aim of this project is to identify, analyse and summarise DNA mutations present in input data, between the control and treatment group's various samples. The biological query it aims to answer is to process the first 200 nucleotides in NGS (Next Generation Sequencing) reads, which by hand would take a long time to do. 

## How To Run
